# Plum standard library

Generated by `plum stdlib-reference`; do not edit by hand.
`bootstrap/check-stdlib-reference` fails when it is out of date.

Everything here is available with no `use` unless its section says
otherwise -- `Net`, `Http`, `Os`, `Time`, `Process`, `Encoding` and `Url` are modules and need one.

A declared function is shown as it is written, receiver first:
`let Array.reverse (xs: Array[T]): Array[T]`. A function the compiler
implements itself is marked `(built in)` and shown in method form:
`Array.map(f: (T) -> U): Array[U]`. Both are callable either way --
`Array.reverse(xs)` and `xs.reverse()` are the same call.

See README.md for the prose introduction.

## `enum Option`

A value that may not be there.

Plum has no null, so absence is spelled here and the checker makes
you handle it.

<a id="Option.is_some"></a>

## `let Option.is_some (o: Option[T]): Bool`

Whether there is a value.

<a id="Option.is_none"></a>

## `let Option.is_none (o: Option[T]): Bool`

Whether there is no value.

<a id="Option.or"></a>

## `let Option.or (o: Option[T]) (fallback: Option[T]): Option[T]`

The first option when it contains a value, or `fallback` otherwise.

`fallback` is evaluated whether or not it is needed. Use `or_else`
when finding the fallback costs something.

<a id="Option.or_else"></a>

## `let Option.or_else (o: Option[T]) (f: () -> Option[T]): Option[T]`

The first option when it contains a value, or the result of calling
`f` otherwise. The lazy `or`: `f` runs only when it has to.

<a id="Option.unwrap_or"></a>

## `let Option.unwrap_or (o: Option[T]) (fallback: T): T`

The value, or `fallback` when there is none.

`fallback` is evaluated whether or not it is needed. Use
`unwrap_or_else` when computing it costs something.

<a id="Option.unwrap_or_else"></a>

## `let Option.unwrap_or_else (o: Option[T]) (f: () -> T): T`

The value, or the result of calling `f` when there is none. The
lazy `unwrap_or`: `f` runs only when it has to.

<a id="Option.map"></a>

## `let Option.map (o: Option[T]) (f: (T) -> U): Option[U]`

Transforms the value if there is one, leaving `None` alone.

<a id="Option.and_then"></a>

## `let Option.and_then (o: Option[T]) (f: (T) -> Option[U]): Option[U]`

Chains an operation that may itself find nothing.

`map` with a function returning `Option` would give
`Option[Option[U]]`; this is the one that keeps it flat.

<a id="Option.ok_or"></a>

## `let Option.ok_or (o: Option[T]) (err: E): Result[T, E]`

Turns nothing into an error, so an `Option` can join a chain of
`Result`s.

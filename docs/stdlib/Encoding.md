## `let percent_encode (b: Bytes): String`

The `Err` arm is unreachable by construction: every byte emitted
above is either an unreserved character or one of `%0-9A-F`, all
of which are ASCII and therefore valid UTF-8. Written as a `match`
rather than an unwrap so that the impossible case is visible
rather than asserted.

# Memory

Generated by `plum doc` from the source. Do not edit by hand.

## `struct Snapshot`

One coherent view of tracked Plum cells, before allocating this record.
Bytes include requested headers, terminators and explicit capacity; they
exclude allocator rounding, registry storage, native buffers and GPU memory.
Reuse keeps the cell's original request. Peaks are process-lifetime maxima.

## `struct Delta`

Allocation traffic and changes in live cells between two snapshots.
Live differences may be negative. Peaks are maxima, not additive traffic.

## `let snapshot (): Option[Snapshot]`

Capture tracked cells at one point. Returns None without --memory-stats.
The snapshot record/Some wrapper are ordinary owned allocations made after
capture; retaining them affects later snapshots. Keep observer state equal
when checking a workload's baseline. This measures requested Plum-cell bytes,
not RSS or all native allocations, and a nonzero live value is not a leak verdict.

## `let delta (before: Snapshot) (after: Snapshot): Delta`

Subtract an earlier snapshot from a later one in the same process.

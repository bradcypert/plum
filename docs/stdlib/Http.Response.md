## `struct Response`

A complete response: status, headers, and the whole body as raw bytes.
Use Response.text to decode UTF-8 explicitly.

## `let Response.text (resp: Response): Result[String, String]`

Decodes the response body as UTF-8, returning Err for invalid text.
This validates without copying the payload; it does not decompress or
interpret Content-Type. Use body directly for arbitrary binary data.

## `struct Request`

An incoming request, with its body preserved as raw bytes.
Use Request.text to decode UTF-8 explicitly.

## `let Request.text (req: Request): Result[String, String]`

Decodes the request body as UTF-8. Invalid UTF-8 returns Err; the raw
body remains available as Bytes. No Content-Type or charset conversion
is inferred, and valid text shares the body's reference-counted storage.

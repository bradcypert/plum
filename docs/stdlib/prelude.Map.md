## `struct Map`

A hash map from `K` to `V`.

PERSISTENT: `Map.insert` returns a new map and leaves the original
alone, so a map can be shared without copying defensively. Keys
need `Eq` and `Hash`. Equal keys hash identically.
NaN is not a supported key, including inside aggregates, because
IEEE equality makes it unequal to itself. References use identity.

<a id="Map.new"></a>

## `let Map.new (): Map[K, V]`

An empty map.

<a id="Map.insert"></a>

## `let Map.insert (m: Map[K, V]) (k: K) (v: V): Map[K, V]`

A NEW map with `k` set to `v`, replacing any previous value. The
original is unchanged. Only the affected trie path is rebuilt.

<a id="Map.get"></a>

## `let Map.get (m: Map[K, V]) (k: K): Option[V]`

The value for `k`, or `None`.

<a id="Map.contains"></a>

## `let Map.contains (m: Map[K, V]) (k: K): Bool`

Whether `k` has a value.

<a id="Map.remove"></a>

## `let Map.remove (m: Map[K, V]) (k: K): Map[K, V]`

A new map without `k`. Removing an absent key is not an error.

<a id="Map.len"></a>

## `let Map.len (m: Map[K, V]): Int`

How many entries.

<a id="Map.keys"></a>

## `let Map.keys (m: Map[K, V]): Array[K]`

Every key, in no particular order.

<a id="Map.values"></a>

## `let Map.values (m: Map[K, V]): Array[V]`

Every value, in the same order as `Map.keys`.

<a id="Map.from_arrays"></a>

## `let Map.from_arrays (keys: Array[K]) (values: Array[V]): Map[K, V]`

A map from parallel arrays, stopping at the shorter. A repeated
key keeps the LAST value.

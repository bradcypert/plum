# NativeBuffer

Generated by `plum doc` from the source. Do not edit by hand.

Owned, bounded native storage for unsafe in/out calls. This is separate
from immutable String/Bytes cells and from their owned CStr views.

## `handle Buffer`

Aliases share one mutable native resource. Its final owner releases the
allocation. Normal exits and panic follow the standard handle contract.

## `let create (capacity: Int): Result[Buffer, String]`

Create empty storage with exactly `capacity` writable bytes. Zero capacity
is valid for binary operations. Native metadata/minimum allocation size
are separate from the reported payload capacity. New storage is zeroed;
logical length starts at zero. Allocation can fail.

## `let length (buffer: Buffer): Int`

Last committed readable prefix. During an edit this remains the previous
length. This metadata query does not access bytes or end the lease.

## `let capacity (buffer: Buffer): Int`

Writable bytes, including the terminator slot when used for text editing.

## `let reserve (buffer: Buffer) (capacity: Int): Result[Unit, String]`

Grow to at least `capacity`, preserving contents. Never shrinks or truncates.
Err while borrowed; failed allocation leaves the old storage intact.

## `let copy_in (buffer: Buffer) (bytes: Bytes): Result[Unit, String]`

Copy immutable bytes into native storage. Err if they do not fit or the
resource is borrowed; neither case changes existing contents. Adds NUL
termination when capacity exceeds the byte length. Exact-capacity binary
input remains valid without a terminator.

## `let copy_out (buffer: Buffer): Result[Bytes, String]`

Copy the committed prefix into independent Bytes while holding a read
lease. Err when another lease is active; later native edits cannot change
the returned immutable value.

## `let text (buffer: Buffer): Result[String, String]`

Copy the committed prefix and validate UTF-8. Includes embedded NULs:
use with_text when a native API instead treats the first NUL as the end.

## `let with_mut (buffer: Buffer) (operation: (RawCStr, Int) -> Result[Int, String]): Result[Int, String]`

Unsafe scoped binary access. The callback receives pointer/capacity and
returns the initialized readable length. Call with all arguments inside
unsafe; this function cannot be partially applied or used as a value.
No pointer may escape or be retained by foreign code. Writes must fit the
capacity. Once the callback begins, Err, invalid length or panic discards
contents. Rejected acquisition leaves contents unchanged.
Conflicting leases/copies/resizes return Err, including reentrant aliases.

## `let with_text (buffer: Buffer) (operation: (RawCStr, Int) -> Result[T, String]): Result[(T, String), String]`

Unsafe scoped C text editing. Capacity includes NUL space. Input must
already be terminated within initialized storage; output must have a NUL
within capacity. Scan, copy and validate UTF-8 while the lease is held;
return (callback result, independent String) before other aliases can edit.
Callback Err, invalid termination/UTF-8 or panic discards contents;
rejected acquisition leaves them unchanged. No pointer may escape.
Calls must be fully applied inside unsafe. Separate buffers are independent;
aliased borrows return Err. The copy is of the text prefix, not capacity.

## `struct Snapshot`

Separate native payload accounting under --memory-stats. Requests count
successful creation/growth; allocated_capacity sums requested capacities.
Live/peak capacity excludes metadata, allocator rounding, other native/GPU
allocations and allocator-internal realloc overlap. Memory.snapshot counts
the small Plum handle/lease cells separately. Snapshot records allocate
Plum cells after freezing these native fields.

## `let snapshot (): Option[Snapshot]`

One coherent native-buffer snapshot, or None when diagnostics are disabled.
Frozen fields are thread-local; reading one does not allocate native storage.

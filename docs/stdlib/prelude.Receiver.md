## `let Receiver.recv (self: Receiver[T]): Option[T]`

Returns Some(value), blocking until a value arrives or every sender is dropped. Queued values are delivered before None; subsequent receives also return None.

Implemented by the compiler itself, so it has no Plum source to read.
